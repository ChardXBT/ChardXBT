# Hey, I'm Eric.

I study Mathematics and Statistics at the University of Toronto, and I build small systems that solve problems I keep running into: repetitive work, messy data, unreliable processes, and the eternal question of whether a task can run itself while I sleep.

Most of my work sits somewhere between automation, data tooling, and practical software. I like turning a fragile manual routine into something observable, cautious, and pleasantly boring.

Some things I’ve made:

- [Self-Recovering Automation](https://github.com/ChardXBT/Self-Recovering-Automation) — a manager for running several automations safely, with failure isolation and proof that a job actually finished.
- [Marketplace Price Tracker](https://github.com/ChardXBT/Marketplace-Price-Tracker) — public, sanitized versions of marketplace-monitoring and buying logic.
- [CS2 Marketplace Trading System](https://github.com/ChardXBT/CS2-Marketplace-Trading-System) — tools for maintaining orders, monitoring opportunities, and keeping inventory work organized.
- [Social Code Scraper](https://github.com/ChardXBT/social-code-scraper) — watches posts, finds likely promo codes with OCR, and sends only new finds to Discord.
- [ACORN Enrollment Runner](https://github.com/ChardXBT/acorn-enrollment-runner) — a deliberately cautious Chrome extension for working through an ACORN enrolment cart.

A fair amount of what I build is private. That is partly because real projects tend to accumulate account details, operational data, and market logic that stops being useful the moment it becomes public. The public repos show the engineering; the private ones contain the parts that would make their own job harder if they escaped.
